## Utilisation dans DevLab

Font Awesome est utilisé uniquement pour les icônes.

Exemples :

- Navigation
- Boutons
- Alertes
- Badges
- Cartes
- Menus
- Tableaux

---

## Bonnes pratiques

Ne jamais modifier les fichiers de Font Awesome.

Les icônes sont appelées directement dans le HTML.

Exemple :

<i class="fa-solid fa-house"></i>

---

## Organisation

Le dossier contient :

- css/
- webfonts/

Aucun autre fichier ne doit être modifié.
