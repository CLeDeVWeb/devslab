## Utilisation dans DevLab

jQuery est utilisé uniquement comme bibliothèque utilitaire.

Principales utilisations :

- Gestion des événements
- Compatibilité avec certains plugins tiers

## Bonnes pratiques

Ne jamais modifier les fichiers jQuery.

Toute extension doit être développée dans :

public/assets/js/

Exemple :

- app.js
- plugins.js
- ajax.js
- modal.js
